## Swagger docs endpoint

To enable the Swagger docs endpoint, set `api.swagger` to true in the `app.toml` file:

```toml

[api]

# Swagger defines if swagger documentation should automatically be registered.

swagger = true
```

After you restart the node, the Swagger docs are available at `http://<node-ip>:<port>/swagger/` (for example, `http://localhost:1317/swagger/`).

<Note>
  The Interchain Accounts (ICS-27) query endpoints are no longer part of the API. The ICA host params endpoint (`/ibc/apps/interchain_accounts/host/v1/params`), the ICA controller params endpoint (`/ibc/apps/interchain_accounts/controller/v1/params`), and the interchain account lookup endpoint (`/ibc/apps/interchain_accounts/controller/v1/owners/{owner}/connections/{connection_id}`) have been removed and will no longer appear in the Swagger spec.
</Note>

<Note>
  Starting with v6.7, IBC transfer (ICS-20) support has been removed, and the transfer query endpoints are no longer part of the API. The escrow address endpoint (`/ibc/apps/transfer/v1/channels/{channel_id}/ports/{port_id}/escrow_address`), the denom hash endpoint (`/ibc/apps/transfer/v1/denom_hashes/{trace}`), the denom traces endpoints (`/ibc/apps/transfer/v1/denom_traces` and `/ibc/apps/transfer/v1/denom_traces/{hash}`), and the transfer params endpoint (`/ibc/apps/transfer/v1/params`) have been removed and will no longer appear in the Swagger spec. To query pre-v6.7 transfer history, run a v6.6 freeze node.
</Note>



<Note>
  Starting with v6.7, the IBC core query APIs have been removed, so the IBC channel, client, and connection query endpoints are no longer part of the API. Paths such as `/ibc/core/channel/v1/channels`, `/ibc/core/client/v1/client_states`, and `/ibc/core/connection/v1/connections` (along with the rest of the IBC core channel, client, and connection query paths) have been removed and will no longer appear in the Swagger spec. The remaining non-IBC query endpoints (epoch, evm, mint, oracle, tokenfactory) stay available. To query pre-v6.7 IBC history, run a v6.6 freeze node.
</Note>

The default API port is `1317`. Make sure that the API server is enabled: set `enable = true` in the `[api]` section of your `app.toml`.
