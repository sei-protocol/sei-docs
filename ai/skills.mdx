Sei Foundation publishes **agent skills**: focused, installable knowledge packs that make your AI coding assistant Sei-aware. This docs site hosts them in the open [`skill.md`](https://www.mintlify.com/docs/ai/skillmd) format. Any assistant that supports agent skills, such as Claude Code or Cursor, can install them.

## Install

Run the `skills` CLI against this site:

```bash
npx skills add https://docs.sei.io
```

The CLI lists every skill this site serves and installs the ones you pick. To install one skill without the prompt, pass its name with `--skill`:

```bash
npx skills add https://docs.sei.io --skill sei-nodes
```

## How the skills work

Each Foundation skill is a single `SKILL.md` file. Its frontmatter tells an assistant when to use it. The body is a short playbook of Sei-specific facts, code, and pitfalls.

## Focused skills or the full sei-skill

Each Foundation skill covers one area. To load one knowledge base that covers every area at once, install the full [sei-skill](/ai/sei-skill) from its repository instead.

| Use a Foundation skill when | Use the full [sei-skill](/ai/sei-skill) when |
|---|---|
| You work mostly in one area, such as contracts | You want every area in one install |
| You want to keep your assistant's context small | You start a Sei project from scratch |
| You compose your own set of skills | You want the full reference files from the sei-skill repository |

## Publish your own skill

Ecosystem teams can publish skills for their own protocols. Any Mintlify site serves the skills in its `.mintlify/skills/` directory. Developers install them with `npx skills add` and your docs URL. Foundation skill content lives in [`sei-protocol/sei-skill`](https://github.com/sei-protocol/sei-skill).
