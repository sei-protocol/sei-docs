sei-skill is a structured knowledge base for AI coding assistants. Install it once, and your assistant gives accurate, Sei-specific answers to Sei questions instead of generic Ethereum defaults. It works with Claude Code, Cursor, Copilot, Windsurf, or any other assistant.

## Why this matters

AI assistants are trained on broad Ethereum knowledge, not Sei's specifics. Without sei-skill, they confidently give you wrong answers like these:

| Without sei-skill | With sei-skill |
|---|---|
| `maxFeePerGas` in transactions | Legacy `gasPrice` (Sei does not use the EIP-1559 base fee) |
| "Finality takes ~12 confirmations" | Instant finality: 1 confirmation is final |
| SSTORE costs 20,000 gas | SSTORE costs 72,000 gas, the same on Sei Mainnet and Sei Testnet. It is an on-chain parameter that governance can adjust ([reference](/evm/differences-with-ethereum#sstore-gas-cost)). |
| `PREVRANDAO` for randomness | PREVRANDAO is not random on Sei. Use Pyth VRF or Chainlink VRF. |
| Generic ERC-20 patterns | Sei precompiles, pointer contracts, dual-address UX |
| `@sei-js/evm` imports | `@sei-js/precompiles` (the current package name) |

## Three knowledge domains

sei-skill covers three areas. You can install all three or only the ones that you need.

**Contracts** covers EVM smart contract development on Sei:
- Foundry and Hardhat setup for Sei networks
- All Sei precompiles (Staking, Governance, Bank, Distribution, JSON, P256)
- Pointer contracts for cross-VM asset bridging
- Gas optimization and awareness of OCC parallel execution
- Account abstraction (ERC-4337) and contract upgradeability
- Verification workflows on Seiscan
- Security patterns and common errors

**Frontend** covers dApp UI development:
- wagmi and viem setup with the Sei chain config
- Wallet integration (Sei Global Wallet, MetaMask, Compass, Ledger, EIP-6963)
- Dual-address UX (`sei1...` and `0x...` addresses from the same key)
- Fast-finality patterns for 400ms blocks
- RainbowKit and ConnectKit integration

**Ecosystem** covers infrastructure and integrations:
- RPC endpoints (public, community, paid SaaS)
- Bridges (LayerZero V2, Circle CCTP v2 for native USDC)
  - IBC is [disabled in both directions](/learn/sip-03-migration#ibc-is-disabled)
- Oracles (Chainlink, Pyth, API3, RedStone)
- Indexers (The Graph, Goldsky, Dune, Moralis)
- DeFi protocols (DragonSwap, Yei, Takara, Saphyre)
- Validators, node operations, and grants

## Quick install

```bash
git clone https://github.com/sei-protocol/sei-skill
cd sei-skill
./install.sh
```

By default, the script installs the skill for Claude Code in `~/.claude/skills/sei/`. For other AI assistants, see the [installation guide](/ai/sei-skill/install).
