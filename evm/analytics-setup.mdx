## Overview

When you set up analytics for your project, you can track user activity, transaction counts, and project growth. This guide shows how to integrate with three platforms that give insights into the performance of your project.

**What you will set up:**

- Token Terminal
- Artemis
- Dune Analytics

**Time required:** 20 to 25 minutes

## Step 1: Sei ecosystem directory + Token Terminal

The Monday form registers your project in the Sei ecosystem directory and automatically submits it to Token Terminal.

Complete the [Monday form](http://forms.monday.com/forms/b6816df94378117836cd0d4046d7213b?r=apse2).

**What happens next:**

- Your project appears in the Sei ecosystem directory
- Token Terminal automatically receives your project information
- Metric tracking starts within 48 to 72 hours

## Step 2: Artemis Analytics

Artemis gives detailed analytics on user activity and transactions for your project.

Complete the [Artemis application form](https://ry0v9n8oa4l.typeform.com/to/sXX203Nk?typeform-source=app.artemisanalytics.com).

**Processing time:** 2 to 4 business days for approval

## Step 3: Dune dashboard

Create custom analytics dashboards with detailed blockchain data.

Follow the [Sei Dune guide](/evm/dune).

**Setup process:**

1. Create a free Dune account
2. Use the pre-built query templates in the Dune guide
3. Customize the queries for your contract addresses
4. Build charts and visualizations
5. Set up an automated data refresh

**Key metrics to track:**

- Daily transaction counts
- Unique wallet addresses
- Token transfer volumes
- Contract interaction patterns

**Setup time:** 10 to 15 minutes with the templates

As your project grows, these platforms help you make data-driven decisions about development and strategy.
