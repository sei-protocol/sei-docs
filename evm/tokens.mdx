#### ERC20 tokens

To view ERC20 tokens in MetaMask, follow the same process as on other EVM chains.
If a token is not listed automatically, import it into your wallet manually. For
detailed instructions, see the
[MetaMask guide on how to display tokens](https://support.metamask.io/manage-crypto/tokens/how-to-display-tokens-in-metamask/).

#### ERC721 NFTs

You must add NFTs to MetaMask manually before you can view them. To add and view
your NFTs in the wallet, follow the steps in the
[MetaMask NFT guide](https://support.metamask.io/manage-crypto/nfts/nft-tokens-in-your-metamask-wallet/).
