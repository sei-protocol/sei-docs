[Pimlico](https://pimlico.io) is an account abstraction (AA) infrastructure provider. With Pimlico, you can integrate smart accounts and gasless transactions into your Sei dApps. This guide shows how to use Pimlico's infrastructure to create a smart account and send your first gasless transaction on Sei Testnet.

## Getting started

### Dependencies

To integrate Pimlico into your Sei dApp, install these dependencies:

```bash
pnpm install permissionless viem dotenv
```

<Info>permissionless.js is an AA SDK that works with any account, paymaster, or bundler implementation. It does not lock you in to one vendor.</Info>

### Setting up Pimlico dashboard

Before you start the integration:

1. Go to the [Pimlico dashboard](https://dashboard.pimlico.io).
2. Create an account. Then generate an API key.
3. Store your API key in a `.env` file:

```shell
PIMLICO_API_KEY='pim_xxxxxxxxxxxxxxxxxxxxxx'
```

## Configuring Pimlico client

First, set up the necessary clients and configurations.

```typescript
import { createSmartAccountClient } from 'permissionless';
import { createPimlicoClient } from 'permissionless/clients/pimlico';
import { createPublicClient, http, Hex } from 'viem';
import { privateKeyToAccount, generatePrivateKey } from 'viem/accounts';
import { seiTestnet } from 'viem/chains';
import { toSimpleSmartAccount } from 'permissionless/accounts';
import { appendFileSync } from 'fs';
import 'dotenv/config';

const apiKey = process.env.PIMLICO_API_KEY;
if (!apiKey) throw new Error('Missing PIMLICO_API_KEY');

// Generate or load private key
const privateKey =
  process.env.PRIVATE_KEY ??
  (() => {
    const pk = generatePrivateKey();
    // Append, so the PIMLICO_API_KEY line stays in .env
    appendFileSync('.env', `\nPRIVATE_KEY=${pk}\n`);
    return pk;
  })();

// Create public client
export const publicClient = createPublicClient({
  chain: seiTestnet,
  transport: http('https://evm-rpc-testnet.sei-apis.com')
});

// Create Pimlico client
const pimlicoUrl = `https://api.pimlico.io/v2/${seiTestnet.id}/rpc?apikey=${apiKey}`;

export const pimlicoClient = createPimlicoClient({
  chain: seiTestnet,
  transport: http(pimlicoUrl)
});
```

## Creating a smart account

Next, create a simple smart account instance. A single EOA signer controls this account:

```typescript
import { toSimpleSmartAccount } from 'permissionless/accounts';

const account = await toSimpleSmartAccount({
  client: publicClient,
  owner: privateKeyToAccount(privateKey as Hex)
});

console.log(`Smart account address: ${account.address}`);
```

<Info>For the full list of smart account types that permissionless.js supports, see the [smart account comparison](https://docs.pimlico.io/permissionless/how-to/accounts/comparison).</Info>

## Setting up the smart account client

To interact with the smart account, create a `SmartAccountClient`:

```typescript
import { createSmartAccountClient } from 'permissionless';

const smartAccountClient = createSmartAccountClient({
  account,
  chain: seiTestnet,
  bundlerTransport: http(pimlicoUrl),
  paymaster: pimlicoClient,
  userOperation: {
    estimateFeesPerGas: async () => {
      return (await pimlicoClient.getUserOperationGasPrice()).fast;
    }
  }
});
```

## Sending a gasless transaction

When the setup is complete, you can send a gasless transaction from your smart account:

```typescript
const txHash = await smartAccountClient.sendTransaction({
  to: '0xd8da6bf26964af9d7eed9e03e53415d37aa96045',
  value: 0n,
  data: '0x1234'
});

console.log(`Transaction included: ${txHash}`);
```

## Complete example

This complete example combines all of the steps:

```typescript
import { createSmartAccountClient } from 'permissionless';
import { createPimlicoClient } from 'permissionless/clients/pimlico';
import { privateKeyToAccount, generatePrivateKey } from 'viem/accounts';
import { createPublicClient, http, Hex } from 'viem';
import { seiTestnet } from 'viem/chains';
import { toSimpleSmartAccount } from 'permissionless/accounts';
import { appendFileSync } from 'fs';
import 'dotenv/config';

async function main() {
  // Initialize clients and account
  const apiKey = process.env.PIMLICO_API_KEY;
  if (!apiKey) throw new Error('Missing PIMLICO_API_KEY');

  // Generate or load private key
  const privateKey =
    process.env.PRIVATE_KEY ??
    (() => {
      const pk = generatePrivateKey();
      // Append, so the PIMLICO_API_KEY line stays in .env
      appendFileSync('.env', `\nPRIVATE_KEY=${pk}\n`);
      return pk;
    })();

  // Create public client
  const publicClient = createPublicClient({
    chain: seiTestnet,
    transport: http('https://evm-rpc-testnet.sei-apis.com')
  });

  // Create Pimlico client
  const pimlicoUrl = `https://api.pimlico.io/v2/${seiTestnet.id}/rpc?apikey=${apiKey}`;

  const pimlicoClient = createPimlicoClient({
    chain: seiTestnet,
    transport: http(pimlicoUrl)
  });

  // Create smart account
  const account = await toSimpleSmartAccount({
    client: publicClient,
    owner: privateKeyToAccount(privateKey as Hex)
  });

  console.log(`Smart account address: ${account.address}`);

  // Create smart account client
  const smartAccountClient = createSmartAccountClient({
    account,
    chain: seiTestnet,
    bundlerTransport: http(pimlicoUrl),
    paymaster: pimlicoClient,
    userOperation: {
      estimateFeesPerGas: async () => {
        return (await pimlicoClient.getUserOperationGasPrice()).fast;
      }
    }
  });

  // Send transaction
  const txHash = await smartAccountClient.sendTransaction({
    to: '0xd8da6bf26964af9d7eed9e03e53415d37aa96045',
    value: 0n,
    data: '0x1234'
  });

  console.log(`Transaction included: ${txHash}`);
}

main().catch(console.error);
```

## What's happening under the hood?

When you send a transaction with the smart account client:

1. The client builds a user operation (a transaction format for smart accounts).
2. The client requests sponsorship from Pimlico's paymaster.
3. The client signs the operation with the private key of the smart account owner.
4. The client submits the operation to Pimlico's bundler.
5. The bundler monitors the chain until the operation is included in a block.

If your smart account contract is not deployed yet, the first transaction also deploys it.
