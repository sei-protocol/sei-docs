**Address:** `0x0000000000000000000000000000000000001012`

The Mint precompile reads the Sei `mint` module: the token release schedule and the state of the current release period. All methods are `view` functions. The precompile is available since v6.7.0.

## Interface

```solidity Mint.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

address constant MINT_PRECOMPILE_ADDRESS = 0x0000000000000000000000000000000000001012;

IMint constant MINT_CONTRACT = IMint(MINT_PRECOMPILE_ADDRESS);

interface IMint {
    function params() external view returns (MintParams memory);
    function minter() external view returns (Minter memory);

    struct ScheduledTokenRelease {
        string startDate;
        string endDate;
        uint64 tokenReleaseAmount;
    }

    struct MintParams {
        string mintDenom;
        ScheduledTokenRelease[] tokenReleaseSchedule;
    }

    struct Minter {
        string startDate;
        string endDate;
        string denom;
        uint64 totalMintAmount;
        uint64 remainingMintAmount;
        uint64 lastMintAmount;
        string lastMintDate;
        uint64 lastMintHeight;
    }
}
```

## Methods

| Method | Returns |
| --- | --- |
| `params()` | The mint denomination and the token release schedule. Each release has a start date, an end date, and an amount. |
| `minter()` | The current release period. It includes the start and end dates, the denomination, the total amount to mint, and the amount left to mint. It also includes the amount, date, and block height of the last mint. |
