Start a new Sei dApp from a working template instead of a blank folder. The [`@sei-js/create-sei`](/evm/sei-js/create-sei) CLI scaffolds a project with wallet connections, Sei network configuration, TypeScript, and styling already set up.

## Scaffold in one command

<CodeGroup>

```bash npx
npx @sei-js/create-sei app -n my-sei-app
```

```bash bunx
bunx @sei-js/create-sei app -n my-sei-app
```

</CodeGroup>

Then install and run the project with Bun:

```bash
cd my-sei-app
bun install
bun run dev
```

Open `http://localhost:3000`. The dApp connects to Sei Mainnet unless `.env.local` sets `NEXT_PUBLIC_CHAIN=testnet`. To use Sei Testnet, copy the template's `.env.example` to `.env.local`.

## What the templates include

<Columns cols={2}>
  <Card title="Wallet connections" icon="wallet">
    The templates use RainbowKit with the generic injected browser-wallet connector. WalletConnect-based wallets also need `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` in `.env.local`.
  </Card>
  <Card title="Sei network config" icon="network-wired">
    The templates support Sei Mainnet (EVM chain ID `1329`) and Sei Testnet (EVM chain ID `1328`). `NEXT_PUBLIC_CHAIN` selects the network.
  </Card>
  <Card title="Type safety" icon="square-check">
    The templates use TypeScript end to end with wagmi and viem, so contract calls and ABIs are typed.
  </Card>
  <Card title="Tooling" icon="screwdriver-wrench">
    The templates use Tailwind CSS and Mantine UI for styling, and Biome for formatting.
  </Card>
</Columns>

<Note>
  You need Node.js to run the CLI and Bun to install and run the generated project. The [Scaffold Sei](/evm/sei-js/create-sei#included-configuration) page lists the minimum versions.
</Note>

## Contribute a template

Templates ship as part of `@sei-js/create-sei`. To add a template, open a pull request in [`sei-protocol/sei-js`](https://github.com/sei-protocol/sei-js/tree/main/packages/create-sei). For example, you can add a DeFi starter, an NFT mint, or an x402 payments dApp. After the template ships in the CLI, it can be listed here.
