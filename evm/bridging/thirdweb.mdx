thirdweb [Payments](https://thirdweb.com/payments?utm_source=sei&utm_medium=documentation&utm_campaign=chain_docs) is a Web3 payment solution that helps you monetize any app or game.

With Payments, your users can onramp, bridge, and swap on any EVM chain, with any EVM token or with fiat. Automatic cross-chain routing makes this possible.

Payments is easy to implement, and its fee-sharing mechanism lets you earn from day one.

## Payments features

- Let users pay for assets in any EVM token on any EVM chain
- Automatic cross-chain routing of transactions
- Earn from day one with the fee-sharing mechanism
- Access a ready-made UI component for easy implementation

## See Payments in action

This code example shows how Payments works:

```jsx
import { createThirdwebClient } from 'thirdweb';
import { PayEmbed } from 'thirdweb/react';

import { createWallet } from 'thirdweb/wallets';
import { sei } from 'thirdweb/chains';

const client = createThirdwebClient({
  clientId: '....'
});

function Example() {
  return (
    <PayEmbed
      client={client}
      payOptions={{
        mode: 'fund_wallet',
        prefillBuy: {
          chain: sei,
          amount: '0.01'
        }
      }}
    />
  );
}
```
