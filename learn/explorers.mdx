## What is a block explorer?

A block explorer is the most common way to look up all kinds of on-chain
information. With an explorer, you do not need to download the entire
blockchain ledger.

Most block explorers have tools to view the network, and some have tools to
interact with it. These tools include:

- Transaction tracking: View and track individual transactions on the
  blockchain. The information typically includes transaction hashes, input and
  output data, tokens transferred, fees paid, and any error messages for the
  transaction. It also includes the addresses of other wallets or contracts
  that a given wallet has interacted with.

- Block information: Details about each block, such as height (sequence),
  timestamp, total size, and details on the transactions in the block.

- Address queries: Find specific wallet addresses with their token balances and
  transaction history. You can also get details on contract addresses and
  non-wallet accounts.

- Network statistics: Statistics and analytics about the blockchain, such as
  the total number of blocks, transaction throughput, network hash rate, and
  staking and governance data.

- Smart contracts: Query smart contract states, deployments, and interactions
  with other wallets or addresses. Some explorers may also show the raw code of
  the contract.

<Info>
  In rare cases, some information may be misinterpreted. Use off-chain data as a guide only.
</Info>
