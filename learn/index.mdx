## Sei Giga: the next-generation architecture

Sei Giga is designed to be the first Multi-Proposer EVM Layer 1. It will be the next generation of the Sei protocol after the Giga Upgrade. It will arrive as in-place upgrades to the live network.

Every validator will propose at the same time. Consensus will finalize only the transaction order. Execution will run asynchronously. On an internal devnet, this architecture sustained more than 5 gigagas per second with ordering finality under 250 ms. Separately, the roadmap target for the Autobahn public testnet is 200,000 TPS.

<CardGroup cols={3}>
  <Card horizontal title="Autobahn consensus" icon="bolt">
    Multi-Proposer BFT: per-validator lanes, an effective steady-state cadence of one cut per 1.5 round trips, and sub-250 ms measured ordering finality.
  </Card>
  <Card horizontal title="Async execution" icon="clock">
    Consensus will fix the ordering. Execution and state attestation will follow, off the critical path.
  </Card>
  <Card horizontal title="Parallel execution" icon="shuffle">
    Block-STM-style optimistic concurrency across all CPU cores.
  </Card>
</CardGroup>
