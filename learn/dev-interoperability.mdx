## Dual address support

Sei uses two distinct address types:

- **EVM (0x) address:** Ethereum-style addresses with the "0x" prefix.
- **Cosmos address:** Bech32 addresses with the "sei1" prefix.

Both addresses are derived from the same public key, so your assets work across
both formats. You can find your corresponding wallet addresses in the Sei
Dashboard.

For more details, read our
[article on interoperability](https://blog.sei.io/sei-v2-interoperability/).

## Virtual machine interoperability

EVM and existing CosmWasm smart contracts coexist on Sei, but they run in
different execution environments. This is a problem for users, because their
wallets typically support only one execution environment. Developers have the
same problem. Existing tools and libraries can interact with only EVM or only
Wasm (for example, EthersJS for EVM and CosmJS for Wasm).

To connect EVM and Wasm, Sei exposes Cosmos-SDK modules and already-deployed
CosmWasm contracts to the EVM through precompiled contracts. New smart contracts
on Sei should be deployed directly on the EVM.

## Precompile contracts

Sei precompiles are smart contracts built directly into the Sei EVM
environment. Users and developers can use them to access Cosmos-SDK functions through the EVM RPC interface.

To learn how to use EVM precompiles, see the
[Example Usage](/evm/precompiles/example-usage) section.
