You need a wallet to manage assets and interact with Sei. There are several
types of wallets, and each type has different features and levels of security.

<Warning>Avoid importing a wallet mnemonic manually from an EVM-only wallet app into a Cosmos-based wallet app, or the reverse. Because the [coin types](https://en.bitcoin.it/wiki/BIP_0044#Coin_type) differ, the import may generate unexpected wallet addresses.</Warning>

## Types of wallets

1. **Software wallets**: These are applications or browser extensions that
   manage private keys and interact with the blockchain. They are easy to use
   and available on both desktop and mobile devices.
2. **Hardware wallets**: These are physical devices that store private keys
   securely offline. They are more secure, but less convenient for frequent
   transactions.
3. **Passkey-based wallets**: These wallets use passkeys for authentication
   instead of traditional seed phrases. This adds another layer of security.

Wallets with coin type 118 use the Cosmos hierarchical deterministic (HD) derivation path. Sei's address-association system still maps the same key to a unique EVM `0x...` address.

For more on coin types, HD paths, and how to derive wallet addresses correctly,
see [HD paths and coin types](/learn/accounts#hd-paths-and-coin-types).
